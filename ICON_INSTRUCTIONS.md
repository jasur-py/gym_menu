# App Icon Generation Instructions

## Quick Method: Use the Icon Generator View

1. Open `IconGenerator.swift` in Xcode
2. Run the preview (⌥⌘P or click the preview button)
3. Take a screenshot at 1024x1024 resolution
4. Save as PNG
5. Add to AppIcon asset catalog

## Manual Method: Create Icon in Design Tool

### Design Specifications:
- **Size**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Design**: 
  - Blue to purple gradient background
  - White dumbbell/barbell icon in center
  - Modern, clean design

### Color Scheme:
- Background: Blue (#007AFF) to Purple (#AF52DE) gradient
- Icon: White (#FFFFFF)
- Shadow: Black with 30% opacity

## Add Icon to Xcode:

1. Open Xcode
2. Navigate to `GymPlanner/Assets.xcassets/AppIcon.appiconset`
3. Drag your 1024x1024 PNG icon to the "App Icon" slot
4. Xcode will automatically generate all required sizes

## Alternative: Use Online Icon Generator

You can also use online tools like:
- [AppIcon.co](https://www.appicon.co)
- [IconKitchen](https://icon.kitchen)
- [MakeAppIcon](https://makeappicon.com)

Upload a 1024x1024 image and they'll generate all required sizes.
