# 📸 Screenshots Folder

## How to Add Your Screenshots

### Step 1: Save Your Screenshots
Transfer your iPhone screenshots to this folder with these filenames:

**Required Screenshots:**
- `main_view.png` - Main exercise list with training group tabs
- `exercise_detail.png` - Add/Edit exercise page with form fields
- `training_groups.png` - Training groups management page
- `settings.png` - Settings page showing customization options

**Optional Screenshots:**
- `calendar.png` - Calendar view overlay
- `dark_mode.png` - App in dark mode
- `drag_drop.png` - Drag & drop feature in action
- `image_gallery.png` - Horizontal image gallery view

### Step 2: Transfer from iPhone

**Via AirDrop (Easiest):**
1. On iPhone: Select screenshots in Photos app
2. Tap Share → AirDrop → Your Mac
3. On Mac: Move files to this folder
4. Rename according to list above

**Via Cable:**
1. Connect iPhone to Mac
2. Open Image Capture app
3. Select screenshots
4. Import to this folder
5. Rename according to list above

**Via iCloud Photos:**
1. Ensure iCloud Photos is enabled
2. Wait for sync
3. Download from Photos.app on Mac
4. Move to this folder
5. Rename according to list above

### Step 3: Verify
The README.md file automatically references these images.

### Screenshot Tips
- Use iPhone 12 or newer for best display
- Take screenshots in Light mode for consistency
- Capture full screen (no cropping)
- Show populated data (not empty lists)
- Include multiple exercises to demonstrate features
